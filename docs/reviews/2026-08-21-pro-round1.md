## Evidence corrections from local verification

The prompt mentioned one observed close-time variance. Subsequent full
raw-batch reconstruction found 14 close-time variance rows and 28 source gap
events totaling 128 missing hours, all before the retrospective OOS boundary.
Therefore the reviewer's proposed one-row/zero-trade-only exception predicate
is not adopted. The implementation instead requires a versioned registry that
pins every accepted event and every affected full row by SHA-256 while leaving
source bytes unchanged.

The reviewer suggested `api.binance.com`; this project retains Binance's
documented unauthenticated market-data-only host
`https://data-api.binance.vision`. A follow-up review must evaluate the exact
implemented allowlist rather than the earlier textual assumption.
